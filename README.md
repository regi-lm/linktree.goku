# 🐉 Linktree Goku

## 📌 Apresentação do Projeto

O Linktree Goku é uma página de links personalizada inspirada no universo de Dragon Ball. O projeto foi desenvolvido para reunir, em uma única interface, os principais links de redes sociais, portfólios, sites e demais plataformas de um usuário, utilizando um layout moderno, minimalista e totalmente responsivo.

Sua proposta é oferecer uma página leve, elegante e de fácil compartilhamento.

---

## ✨ Funcionalidades

- ✔️ Exibição da foto de perfil
- ✔️ Lista personalizada de links
- ✔️ Botões interativos
- ✔️ Interface inspirada em Dragon Ball
- ✔️ Layout moderno
- ✔️ Design responsivo
- ✔️ Navegação simples e intuitiva
